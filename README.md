## Featured project
 
**[L7 Adaptive Defense](https://github.com/berkkaradas/l7-adaptive-defense)** is my MSc dissertation: an identity-aware defence against application-layer DoS attacks for microservices. A risk engine scores each identity from Kafka signals, off the request path, and the gateway responds step by step: rate limit, then tarpit, then drop.
 
- Caught a low-and-slow brute-force attacker in 5/5 runs (median 8.0 s); a static rate limiter caught 0/5
- Refused none of the requests from innocent users sharing the attacker's IP
- Kept serving traffic through an 89-second Kafka outage
